# Оно тебе надо

Учебный проект Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Макет реализован на HTML и CSS. Для раскладки используются Flexbox и Grid. Страница рассчитана на ширину 1100 пикселей.

Репозиторий: https://github.com/meloch287/ono-tebe-nado-ad

Для просмотра откройте `index.html` в браузере.
